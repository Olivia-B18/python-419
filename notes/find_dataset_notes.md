# Finding a Dataset

## Spotify Datasets

### [YES] Track Data on 114K Songs

URL: https://www.kaggle.com/datasets/priyamchoksi/spotify-dataset-114k-songs?resource=download

Data Format:
* 1 CSV

Notes:
* **About:** Spotify tracks, including artist, track name, quantitative and qualitative data about each track.
* Must make free account with Kaggle
* Provides explanation of column data
* Lots of columns
* Few unmarked entries
* 114K observations
* From 2024

### [MAYBE] Track Data on 1M Songs

URL: https://www.kaggle.com/datasets/amitanshjoshi/spotify-1million-tracks/data

Data Format: 
* 1 CSV

Notes:
* **About:** Same as 114K data set but without the album name column and more data
* Has release year
* Provides explanation of data
* Way more data than I need for this project
* From 2023

### [NO] Feature Collaboration Network

URL: https://www.kaggle.com/datasets/jfreyberg/spotify-artist-feature-collaboration-network?select=nodes.csv

Data Format:
* 2 CSV's (edges and nodes)

Notes:
* **About:** Tracks spotify artist info like song genres they fall under, their popularity and followers, and a separate table tracks any collaborations between artists
* My 114K already gives me some collaborations as well as the exact song the collab happened on though, so nah
* Provides explanation of data
* Pretty clean
* Lots of data
* From 2022

### [NO] Song Lyrics

URL: https://www.kaggle.com/datasets/carlosgdcj/genius-song-lyrics-with-language-information

Data Format:
* 1 CSV

Notes:
* **About:** Tracks artist and title with lyrics, language, and views
* Has release year
* Provides explanation of data
* Needs some cleaning
* Tracks more than just songs - books and poems too
* Raw data too big - 9 GB
* From 2022

## Bird Datasets

### [NO] Cornell Lab of Ornithology

URL: https://ebird.org/data/download 

Data Format:
* Several TXT's from sample zip

Notes:
* **About:** does not give much useful info on the bird itself - just about when/where it was spotted
* Must make free account with Cornell Lab
* Must submit data request

### [NO] Avonet

URL: https://opentraits.org/datasets/avonet.html

Data Format:
* Some CSV and XLSX, one TXT, and miscellaneous others

Notes:
* **About:** hard to tell; appears to be about measurements of bird body parts
* Don't have proper tools to view everything
* Minimal explanation of what the data is
* No common names of birds - only scientific

### [MEH] Dryad

URL: https://datadryad.org/dataset/doi:10.5061/dryad.1zcrjdg56

Data Format:
* 7 CSV's of data
* 1 XLSX of metadata

Notes:
* **About:** bird feeding habits from various taxonomies
* Provides explanation of data
* Provides context of what data was used for

### [MEH] Australian Birds

URL: https://opentraits.org/datasets/australian-birds

Data Format:
* 1 CSV

Notes:
* **About:** various info about Australian birds, including body mass, feeding behavior, and categorization
* Associated paper linked
* Scientific and common names included
* Difficult to understand data at a glance

### [NO] EltonTraits

URL: https://esajournals.onlinelibrary.wiley.com/doi/10.1890/13-1917.1

Data Format:
* 2 TXT's of data
* 2 TXT's of references

Notes:
* **About:** diet, foraging strata, foraging time, body size, etc.
* Requires a lot of filtering and cleaning data
* No provided info on what columns mean
